Det här är ett flersidigt webbprojekt med fiktivt företag Novodisk Revonvirg.

### Filstruktur

- index.html
- about.html
- products.html
- portfolio.html
- contact.html
- css/style.css
- images/img1.jpg
- images/img2.jpg
- images/img3.jpg

### Innehåll

- Semantisk HTML (header, nav, main, section, footer)
- Extern CSS i css/style.css
- Flexbox / Grid för layout
- Pseudo-klass :hover
- Minst en lista, en tabell, extern länk, formulär med action-url
- Responsiv design med media queries
